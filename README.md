# Proyecto APT — Plataforma de Publicación Asistida por IA para Cámara Gremial

> **Estado:** Fase inicial de levantamiento de requisitos (kickoff). Este README se irá actualizando a medida que se definan más detalles con el cliente.

## Contexto

El cliente es una **cámara gremial en Chile**, organismo sin fines de lucro. Actualmente sus publicaciones (artículos, boletines o revista institucional) son de circulación **privada/interna**, y el objetivo del proyecto es abrir esa información al público general a través de un sitio web o revista digital.

## Problema a resolver

La cámara genera contenido de forma manual y lo mantiene con acceso restringido. No existe hoy un mecanismo que les permita **recopilar información, redactar contenido y publicarlo de forma ágil y abierta al público**.

## Objetivo general

Desarrollar una plataforma que permita a la cámara **publicar artículos/contenido de forma pública**, utilizando **inteligencia artificial** como apoyo en el proceso de redacción, manteniendo siempre una instancia de **revisión humana** antes de la publicación final.
